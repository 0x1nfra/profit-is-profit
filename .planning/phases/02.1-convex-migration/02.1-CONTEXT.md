# Phase 2.1: Convex Migration - Context

**Gathered:** 2026-02-22
**Status:** Ready for planning

<domain>
## Phase Boundary

Replace the Supabase data layer entirely with Convex — including auth, data storage, and real-time delivery. Eliminate the `as any` casts in trade-service.ts, restore full type safety via generated Convex types, and enable real-time reactive updates for wallet balances and trades. Full Supabase dependency removed. App must be fully functional end-to-end after migration (connect wallet → setup wallets → sync trades → view dashboard).

## Implementation Decisions

### Auth handling
- Migrate auth fully to Convex — remove Supabase auth, do not keep Supabase for auth-only
- Wallet sign flow (wallet signs message → session created): Claude decides the cleanest Convex Auth approach
- Middleware session handling: Claude picks the most practical approach (cookie vs Convex auth state)
- Full Supabase removal: delete `src/lib/supabase.ts`, remove `@supabase/supabase-js` package, clean all Supabase env vars from the project

### Real-time scope
- Enable real-time reactive updates now — don't defer to Phase 3+
- Live updates for: wallet balances (trading + vault SOL/USD), trade list, sync status indicator
- Sync button stays — user manually triggers Helius fetch; Convex delivers results reactively (no auto-sync on load)
- Convex action vs Next.js API route for sync: Claude decides the right architecture

### Data preservation
- Clean start — no production data in Supabase, no migration scripts needed
- Tests (229 passing) test pure business logic with no DB dependency — Claude assesses whether any test infrastructure changes are needed; update if they do

### Migration boundary
- Migrate all four tables to Convex now: `wallets`, `trades`, `user_state`, `goal_settings`
- API route vs Convex functions decision: Claude picks the right pattern per route
- Delete `src/migrations/` folder (SQL schema files no longer needed)
- Definition of done: full end-to-end flow works on Convex (connect wallet → setup wallets → sync trades → view dashboard)

### Claude's Discretion
- Convex Auth integration pattern (how wallet signing maps to Convex Auth primitives)

- Test infrastructure changes (if any needed)
