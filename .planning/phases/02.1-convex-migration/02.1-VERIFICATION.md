### Noteworthy Implementation Deviations (Not Gaps)

The following are deviations from plan specs that were **correctly resolved** during execution:

1. **JWT_PRIVATE_KEY format:** Plan 03 specified `JSON.parse(process.env.JWT_PRIVATE_KEY!)`. The actual key in `.env.local` is a raw PEM string (not JSON-stringified), so `JSON.parse` was removed. The fix was documented in Plan 05 summary as "JWT_PRIVATE_KEY is PEM string not JSON". The current implementation (`importPKCS8(privateKeyPem, 'RS256')` directly) is correct.

2. **`useAction` instead of `useMutation` for sync:** Plan 04 spec showed `useMutation(api.sync.syncWalletTrades)` but Convex actions require `useAction`. Dashboard correctly uses `useAction`. Documented in Plan 04 summary.

3. **`pisp-auth-change` custom event:** Not in original plan specs but added during E2E to resolve the ConvexClientProvider cookie-timing bug. Implemented in `ConvexClientProvider.tsx` (event listener) and dispatched from `page.tsx` and `dashboard/page.tsx`.

4. **Navigation guards moved to `useEffect`:** Plan 04 showed render-time `if (wallets === null) { router.push("/") }`. The actual dashboard correctly uses `useEffect` to avoid React 18 strict mode render-time side effects.

These are correct improvements, not gaps.
