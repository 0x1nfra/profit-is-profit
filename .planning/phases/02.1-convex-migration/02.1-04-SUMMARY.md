## Decisions Made

- **useAction vs useMutation for actions:** Convex actions use `useAction` from `convex/react` — not `useMutation`. The TypeScript type system enforces this: `FunctionReference<"action">` is incompatible with `useMutation`'s expected type. Fixed from plan template which showed `useMutation` for the sync call.
- **Explicit type annotations in sync.ts:** Convex `_generated` types create circular inference. Added `SyncResult`, `TradeRecord` type aliases and parameter annotations to resolve `TS7022`/`TS7023` implicit any errors.
- **convex/sync.ts imports from src/lib/:** Convex "use node" actions run in Node.js and support relative imports outside the `convex/` directory. Import path `../src/lib/helius-client` works correctly — verified by `npx convex dev --once`.
