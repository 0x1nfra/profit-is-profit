## Decisions Made

- **trade-service.ts replaced with deprecation stub** (`export {}`) rather than deleted outright — keeps git history traceable and avoids phantom import errors
- **health-check page rewritten** around Convex env vars: `NEXT_PUBLIC_CONVEX_URL`, `NEXT_PUBLIC_CONVEX_SITE_URL`, `JWT_PRIVATE_KEY`, `HELIUS_API_KEY`
- **pnpm used (not npm)** — project is pnpm-managed; npm throws an arborist bug with pnpm symlinks
- **pisp-auth-change custom event:** ConvexClientProvider mounts once before sign-in cookie exists. Custom event triggers re-read — simpler than shared state store or polling.
- **Wallet Standard auto-discovery:** `wallets={[]}` lets Wallet Standard detect Phantom/Solflare automatically. Explicit adapters caused duplicate wallet keys.
- **JWT_PRIVATE_KEY is PEM, not JSON:** `JSON.parse` was wrapping PEM in quotes, breaking `importPKCS8`. Fix: pass env var directly.
- **Single routing target post-auth:** Always push to `/dashboard`; dashboard determines if setup redirect needed via `useQuery(wallets)`.
