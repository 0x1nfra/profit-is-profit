## Decisions Made
- Used `{ extractable: true }` option for jose@6 `generateKeyPair` — v6 uses WebCrypto API which defaults to non-extractable keys (breaking the export step)
- Added separate `CONVEX_SITE_URL` env var (server-side only) alongside the pre-existing `NEXT_PUBLIC_CONVEX_SITE_URL` — auth.config.ts runs server-side and should not use a NEXT_PUBLIC_ prefixed var directly
- Kept camelCase throughout schema to match TypeScript conventions and eliminate the `as any` casts that existed when field names mismatched between snake_case DB and camelCase app
